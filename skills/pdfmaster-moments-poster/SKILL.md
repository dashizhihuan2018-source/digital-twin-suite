# 朋友圈海报：PDFMaster案例

以完整主视觉吸引注意，用真实功能解释价值。PDFMaster是已发布的学习案例，不是所有产品的品牌、卖点或固定模板。

指定该案例时先读[公开案例与复用方法](references/pdfmaster-example.md)，实际打开其中的海报参考；若拿不到图，明确只有文案/源码证据，不靠记忆猜画面。其他产品重新核实主张，不照搬“一个应用，三重自由”。

## 制作配方

1. 锁定产品名称、实际版本、受众、必须功能、可用真实UI、CTA和允许动作。朋友圈单图可先采用竖版候选；1024×1536、1080×1920是候选而非平台强制标准。用户只要图片时只交图片；配文、PPT或影片按明确请求提供。
2. 主文案采用“产品名—主张—一句价值—主次功能”；有已核实行动目标且本次需要引导时再加CTA，无目标时省略，不阻塞已有海报。PDFMaster案例：主张“自由创作，灵感无界。”；三项“PDF工具集、无限画布、无边记”。在线画布与本地画板区别保留在相应区域，AI联网、自备Key/独立计费等影响选择的属性在对应功能附近说明。新产品没有证据的免费、买断、离线或跨平台承诺不填入。
3. 按事实安排一幅大主视觉与必要功能分区。可借鉴案例的米白纸感、朱红标题、赭金细线和宋体层级；产品真实UI保持身份与清晰，截图不能被生成模型重画后充当功能证据。仅获视觉参考权利的摄影、Logo与素材不复制进新作品。
4. 需要生图时用当前图像生成能力出完整视觉候选，明确标题和留白。需要真实网站原文/界面时，以原生排版组合真实素材即可，不强制整张重生。用户要求源文件时再把背景、原生文字、Logo、UI与真实二维码分层；不要把位图铺满PPT叫完全可编辑。
5. 本用户未另指定时用真实思源宋体标题与清晰无衬线正文；记录实际字体族/字重/文件与许可。AI图里宋体字感不算已加载真实字体。检查标题断行、对比、主要UI和完整需求，不为凑等权卡片删卖点。
6. 需要二维码时，使用当次确认的公开HTTPS目标生成标准矩阵，保留四模块静区；整张输出核预期数量与全部payload，原图、约390px显示和分享压缩版分别检查。案例自带码指向PDFMaster项目，不能直接复用到其他产品；没有要求码不擅加。

## 验收与交付

直接显示完整PNG，不仅交文件链接、设计说明或SVG代码；按请求附朋友圈短文或可编辑源。实际看整图与手机尺度，核中文、UI、码、版权与边界；记录图像像素、输入版本、输出SHA、字体、素材权利与未验项。

页脚默认`© {真实年份} Nankong`；摄影/字体必须署名和许可在画内或随附文件按原条款保留。内部失败日志和验收pending进入QA，公众画面采用宣传文案；影响判断的限制不随“删除注释”一并删掉。机器扫码、手机微信长按、人工接受与实际发朋友圈分别记账；本地制作不自动发布。

调用示例：`使用 $pdfmaster-moments-poster，为这个产品做一张朋友圈海报。参考PDFMaster的层级，不复制品牌与摄影；只交图片和配文，不做PPT或发布。`
