# 默认配音参考

记录日期：2026-10-28。

## 已确认的声音基线

本套件的默认参考是 PDFMaster 公开演示片中的**同一款合成清晰年轻女声**。这是用户对既有长丰成片音色身份的确认，不代表未来每段新生成内容都已通过自然度、发音或最终听审。

- 公开试听：[PDFMaster 演示视频](https://dashizhihuan2018-source.github.io/PDFMaster/media/pdfmaster-demo.mp4)
- 参考区间：`00:10.65–00:21.45`
- 参考文本：`无限画布，图片、视频和灵感自由铺开。无边记，便笺、手绘和资料随手串联。`
- 本地历史生成条件：MLX-Audio + `Qwen3-TTS-12Hz-0.6B-Base`
- 随机种子：`24`
- `temperature`：`0.65`
- `top_p`：`0.9`
- 后处理约束：不变速、不变调、不加背景音乐

2026-10-28 以 HTTP Range 请求复核该公开 URL，响应为 `206 Partial Content`、`Content-Type: video/mp4`；这证明当时可访问，不保证永久在线。

## 正确复现方式

1. 只在你拥有参考声音和素材使用权时，从公开演示片的上述时间段制作**本地临时参考**。
2. 转写必须与参考片段逐字匹配，使用 Base 模型的 `ref_audio + ref_text` 克隆路径。
3. 固定模型版本／revision、seed、temperature 和 top_p；分段生成时保存每段文本、参数与音频哈希。
4. 保持原速、原调、无 BGM；裁静音也应记录规则，不能悄悄改变节奏。
5. 对姓名、楼号、设备名和英文缩写做正常音量人工听审；技术生成成功不等于听感通过。

安装与 API 示例见 [本地模型安装与离线运行](local-models.md)。历史工程使用的是当时本地接口；新环境应按当前 MLX-Audio 文档验证接口，不能把旧调用参数未经测试地套到未来版本。

## 身份与授权边界

- 仓库只保存公开试听链接、时间区间、文字和参数，**不打包**从视频裁出的 WAV、模型缓存、克隆提示或任何私人声音素材。
- `CustomVoice` 的 `Vivian` 是 Qwen 官方内置 speaker。即使描述相近，也不能称为本参考的“同一声音”；需要复现本基线时应使用已授权参考片段和 **Base** 模型。
- 不把其他项目、同事或私人声音并入本公共默认参考。
- “同款已确认”只适用于已有基线的音色身份；新脚本、新模型版本、新文本或新成片仍需另行听审。
- 公开发布前再次确认参考素材、模型和输出的许可条件；不得暗示现实人物背书。
