# 轻量化数字孪生模型制作

交付是目标浏览器可用的模型层与验证记录，不只是一个更小的文件。本技能不依赖私人模型或付费服务。

## 输入与基线

取得有权处理的可编辑源、当前GLB、目标设备／加载器、锁定项、体积与首屏预算。源只读；候选另存。记录单位、轴、世界变换、语义ID、相机和代表性近景。先运行本目录：

```sh
python3 scripts/audit_glb.py building.glb > baseline.json
```

工具只检查容器与JSON统计，不解码压缩几何、不证明无损、BIM语义或视觉通过。加载器未知时先保留无扩展兼容基线，不把Draco/Meshopt/KTX2设为唯一可用输出。

## 选择动作

| 观察 | 动作 | 比较证据 |
| --- | --- | --- |
| 纹理占大头 | 从原图按真实用途生成网页派生；保护文字、PV格栅、透明边和法线 | 尺寸、色彩空间、alpha、近景像素 |
| 重复家具／植栽 | 确认真正同原型后实例化 | 原型、世界矩阵、点击ID不变 |
| 压缩几何大 | 经目标loader验证后选Meshopt或Draco | 解码后POSITION/normal/UV/拓扑及误差 |
| 首屏不需全部内容 | 建筑／环境／语义／家具分层按需加载 | 完整依赖与首次／回进请求数 |
| 仍超预算 | 给剩余成本与可选LOD、减面、合图方案 | 新增损失必须落在获准范围 |

每次只改一种主要策略，别把全部动作混在一个“优化”里。无损和有损分别计量；压缩包／HTTP传输与GLB本体字节分别记。不能因25MB目标删除锁定几何或用生成园区替换原模型。目标不可达时交付实际体积、前三成本与需要新决定的动作。

## 输出与验收

交付源／候选哈希、层清单、稳定ID映射、原型与实例变换、decoder和许可、体积口径、损失说明及回退。

1. 文件：完整下载、MIME／必要Range、哈希、无漏依赖。
2. 结构：实际loader解码，单位、世界矩阵、语义与原对象对应；本工具的JSON计数不替代此门。
3. 行为：桌面与明确尺寸手机冷启动、近景、核心点击、反复进入；不得再次下载相同GLB或产生空画布。
4. 视觉：同机位材质／轮廓／文字／玻璃对照，注明人工接受状态。体积下降不替代质量验收。

长丰可复用的经验是建筑与环境分层、本地decoder、同一场景复用和外部语义代理；不是“所有模型均可从1GB压成25MB”的承诺。常见错误：合并网格后靠名字找楼、仅看GLB头、回进重建renderer、把压缩后的未知纹理当原图。

## 最终版经验落地

权威来源是[长丰最终网页](https://szls-changfeng.maip.top/EMS-changfeng/?twin=1#/page/ems-overview)与[根版本清单](https://szls-changfeng.maip.top/version.json)，2026-10-28回读为V1.4.12。最终方案保留原GLB，建筑/环境/语义代理分层，不把“进入特效不再额外加载园区”误解为首屏没有多个合法层。

五栋展示编号与旧对象映射单列，合并02只为导航凸包；不可合并源节点后丢失点击/报警绑定。停车面、雨棚与光伏顶面的针对性修复采用局部法线/材质/层面分离补丁，锁定未改的POSITION、UV、索引和原始哈希；这与全模型减面不是同一操作。公开清单陈述的修复仍需新项目实际loader/近景复核。
