# 数字孪生全链路

从同源模型到网页、影片、海报与可复用方法。先确定权威版本、数据真实性、素材权利与验收门，再分派制作。

本技能的主要工程经验来自用户指定的[长丰最终版](https://szls-changfeng.maip.top/EMS-changfeng/?twin=1#/page/ems-overview)，不是本地旧网页。做同类工程前读取 [最终版复用契约](references/changfeng-final.md)，包含五栋映射、同场景增强、原业务保护与实测边界。源网站版本会更新，使用时重新核对。

## 开工清单

1. 读取项目AGENTS与当前交接；锁定source/模型/数据/网页版本，保留用户草稿，创建独立候选输出。
2. 盘点源文件大小、结构、纹理、语义ID、坐标单位、许可证和公开范围；资产采用允许清单，私有凭证不进日志/网页/Git。
3. 定义设备、网络、首屏、帧时间、视觉保真、交互、片长/分辨率预算。体积是约束，不是牺牲几何/功能的唯一目标；不可兼得时报告量测与方案。
4. 指标和动画标注 live/recorded/simulated/demo/unknown；看起来真实不等于实测，概念室内不等于真实BIM。

## 工作流

同源模型基线 → 可逆轻量化 → 真实网页交互 → 生命周期受控特效 → 产品/FPV分镜 → 固定帧录制 → 同源海报 → 版权清单与公开包。

- 网页复用同一renderer/camera/canvas与模型；效果退出恢复原状态。展示名、模型ID和设备绑定分层。
- 增强入口只扩展原运行壳，不替换原业务。隔离演示拒绝原业务API/写请求，保存失败必须如实显示；插件/实验dist不含完整原站时禁止覆盖原站。
- 海报从最终版本真实画面取图；注明版本、作者、真实功能和原始/示意属性。不能用概念渲染冒充已完成交互。
- 新生成配音使用已授权参考；默认原速原调无BGM。项目无参考时不要借用其他人声音，先交静音示例/标缺口。
- 影片锁定全局帧时钟、相机eye/target/FOV、台词词点；不同场景/项目的素材不默默混入。

## 四道独立验收门

1. **结构/技术**：资源可解析、功能真实、解码完整、数据模式准确、自动测试通过。
2. **视觉/视听**：固定近远景、动线净空、材质与风格、字幕、正常音量听审；不由测试结果替代。
3. **交付/发布**：干净环境恢复、下载完整、Git与网页版本一致、匿名链接/播放实测、许可清晰。
4. **人类接受**：单独记录待审/通过/退回。没有用户反馈不能写“用户已验收”。

只获得“诊断”请求时不实施修改；“制作并公开”允许该范围内正常构建发布，不扩大到生产数据变更、收费服务、真人克隆或社交账号发帖。

## 交付清单

按本次范围交源码、可编辑模型/分镜、GLB与语义映射、网页、实际视频与海报、所用技能、安装教程、声音参考、素材清单、哈希/版本和验证报告；九技能可独立调用，不强制每次制作全部成果。公开包排除私有模型/客户数据/密钥/缓存；第三方许可证随资产保留。

总结经验按“遇到的问题→采取的方法→可验证证据→仍未验证的边界”写，区别历史证据与本轮实测，不捏造压缩率、节能率、原生4K或全平台通过。
