# 从海报到发布网站，让成果被看见

从朋友圈一张图，到视频封面，再到承接介绍、演示与下载的产品官网，用真实内容与清楚的视觉语言，把项目价值讲给更多人。

## 海报制作，一个入口

[海报制作技能](../skills/poster-production/SKILL.md)帮助选择用途、组织文案与素材，交出能直接看到的完整画面。朋友圈海报、片内开场、平台封面与宣传长图各有任务，不用一张图勉强代替所有场景。

## 朋友圈海报：以PDFMaster为例

[查看PDFMaster原版海报](https://raw.githubusercontent.com/dashizhihuan2018-source/PDFMaster/9174f2954acae708fe74e9a7f0b37cfd5ee78790/docs/media/pdfmaster-poster.png)。米白纸感与朱红宋体建立记忆，大幅真实界面展示产品，三项能力按主次展开：PDF工具集、无限画布、无边记。

[朋友圈海报技能](../skills/pdfmaster-moments-poster/SKILL.md)提炼文案、视觉层级、真实UI、字体与手机阅读方法。借鉴的是表达方式，不是复制品牌、摄影或功能。只要图片时，就只做图片；配文与源文件按需提供。

## 视频封面海报：以长丰数字孪生为例

[进入长丰最终数字孪生](https://szls-changfeng.maip.top/EMS-changfeng/?twin=1#/page/ems-overview)。围绕建筑主体、空间关系与影片内容安排构图，让一眼可读的标题与真实画面相互成就。

[视频封面海报技能](../skills/video-cover-poster/SKILL.md)区分片内开场、平台封面、宣传海报和实际末帧，覆盖画幅、留白、裁切与时间轴。长丰最终产品片保留原开场封面的经验可迁移，但私有影片与封面不随公共技能分发。本站海报V1.3.0/R5是另行批准的技术示例，不冒称该产品片封面或当前网站新录屏。

## 产品发布网站设计与UI：以PDFMaster为例

[访问PDFMaster官网](https://dashizhihuan2018-source.github.io/PDFMaster/)。从“自由创作，灵感无界”的主张，到真实演示、功能目录、教程和版本下载，内容与界面共同完成一次清楚的产品介绍。

[产品发布网站技能](../skills/product-launch-website/SKILL.md)把设计与UI作为同一任务：内容结构、视觉令牌、响应式布局、媒体播放、可用控件与真实下载入口一起交付。公众读到价值，重要的平台、联网、费用与安装属性也能在选择时查到。

## 独立调用，按需协作

新增四技能与原有数字孪生、模型、发布片、穿越机、特效一起，形成九项独立创作能力。PDFMaster媒体在原站查看，套件不镜像或附带原海报、摄影、UI与声音文件；[原媒体说明](https://github.com/dashizhihuan2018-source/PDFMaster/blob/9174f2954acae708fe74e9a7f0b37cfd5ee78790/docs/media/README.md)保留署名和权利边界。长丰媒体继续遵守本站独立许可，不因增加技能扩大加工或发布授权。
