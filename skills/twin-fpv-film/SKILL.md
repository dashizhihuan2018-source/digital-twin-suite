# 数字孪生穿越机视频

让连续运动解释空间：建立方向—接近入口—穿过通道—揭示主体—安全收尾。FPV不是快速推拉镜头，也不能用“视觉刺激”掩盖穿墙。

参考[长丰最终版](https://szls-changfeng.maip.top/EMS-changfeng/?twin=1#/page/ems-overview)（2026-10-28为V1.4.12）的同场景、不可变源模型和可还原相机经验，不把网站“巡检漫游”直接改称已验收FPV。正式FPV仍要独立验证连续航线、净空与原生时序；受限旧穿越素材不随技能分发。

## 先锁定输入

确认模型、参考片和音频的使用权；明确室内外范围、尺度、通道宽高、目标画幅/fps/时长。没有入口和内部结构时，不虚构能够穿入实体；可用原创建筑示意，但必须标注非实景。

旧场景和源片只读，新镜头写独立目录。HUMAN-only限制AI查看/处理，与传统渲染作品公开许可分别核对：明确仅本地审看的素材不上传；指定媒体另获公开许可时只按该版本、渠道和用途展示，仍不交AI审片。公开许可不扩大到源资产、商用或其他媒体。

## 航线与相机

1. 用顶视图标记起终点、可飞空域、障碍、近裁面和安全半径，先低分辨率预演。
2. 建立一条连续曲线，建议弧长重采样再规划速度；控制速度/加速度/角速度，避免样条参数恒速造成实际忽快忽慢。
3. 眼点、目标点与FOV全部登记。目标点沿路径前视，bank随曲率缓入缓出，不能每帧重新lookAt导致滚转跳变。
4. 用全局帧时钟计算曲线位置、朝向与动效；避免分段重置、急停后瞬移、硬拼不同场景。
5. 净空不只检查离散点：检查连接线段，并考虑相机近裁面/视锥、树冠、栏杆、玻璃和突出构件。透明材质仍可能是实体。

## 净空工具

本技能目录执行：

```bash
python3 scripts/check_route.py route.json
```

```json
{"radius":0.3,"points":[[-2,2,0],[2,2,0]],"boxes":[{"min":[-1,-1,-1],"max":[1,1,1]}]}
```

工具检查折线路径与扩张后的轴对齐包围盒。安全半径与坐标必须同单位。它是保守粗筛，不是精确网格碰撞，也不证明曲线插值段或视锥安全。曲线需要足够密的采样，再检查实际曲线/网格和逐帧画面；若包围盒含通道，应细化碰撞代理，不能直接删除障碍以“通过”。

## 录制与交付

- 明确源像素、画布、DPR、输出像素；帧序列 `t=frame/fps` 与全局动画一致。离线录制30fps不是实时30fps承诺。
- 原生效果避免用插帧掩盖相机抖动；先修航线/前视/角速度，再调运动模糊。
- 报告总帧数、最长停顿、路径长度、速度区间、最小净空与碰撞方法，未测项不编造。
- 交付成片、相机路径/时序、预演、净空报告、模型与素材许可、ffprobe/全片解码结果和关键帧接触表。
- 人工看首尾及最近障碍段；手机和桌面实播。技术、视觉审核、公开发布和用户接受分开记。
